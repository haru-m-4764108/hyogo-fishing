# 兵庫南部 釣り情報（自分用）

兵庫県南部（阪神・神戸・明石・播磨・淡路）の釣り場情報を1ページにまとめるアプリです。
GitHub Actions が1日7回情報を集め、GitHub Pages でスマホから見られるようにします。

## 見られる情報

| 情報 | 取得元 | 方法 |
|---|---|---|
| 釣果 | フィッシングマックス | 釣果記事のRSS（大阪・和歌山は除外） |
| 釣果 | 釣りビジョン | 大阪湾（兵庫）・播磨灘・淡路のエリアページ |
| 釣果 | 尼崎市立魚つり公園 | 公式サイトの日別釣果表（魚種・サイズ・匹数・水温） |
| 潮見表 | 気象庁 潮位表 | 神戸・明石・姫路・洲本・尼崎・西宮の10日分。潮名は月齢から計算 |
| 近くの釣具屋 | OpenStreetMap | 各釣り場から15km以内で近い順に6店（1日1回更新） |
| イベント | Googleニュース検索・尼崎魚つり公園・フィッシングマックス | 釣り大会・教室・体験イベントの記事 |
| 事故・注意情報 | Googleニュース検索 | 兵庫県内の釣り中の事故の記事 |
| SNS | X / Instagram / YouTube / TikTok / Bluesky / Google | 釣り場ごとの検索リンク（※） |
| 仕掛けガイド | アプリ内に収録（`docs/rigs.js`） | 15種類の仕掛け・32魚種。道具・コツ・兵庫南部の釣期・解説動画（YouTube 41本） |
| 釣りメモリー | このブラウザの中（IndexedDB） | 写真＋魚種・サイズ・仕掛け・メモ。撮影日時・位置・潮名は自動入力。zipでバックアップ |

※ X・Instagram は無料で使える検索APIがなく、Bluesky も公開検索APIを閉じているため、
アプリ内に投稿を取り込むのではなく、各アプリの「最新」検索結果を直接開くボタンにしています。

## 初回セットアップ（GitHub Pages で公開）

1. GitHub で新しいリポジトリ（例: `hyogo-fishing`）を作る。**Public** にすると Pages が無料で使えます。
2. このフォルダを push する:
   ```bash
   cd ~/hyogo-fishing
   git remote add origin https://github.com/<ユーザー名>/hyogo-fishing.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages** で「Source: Deploy from a branch」「Branch: `main` / `/docs`」を選んで保存。
4. **Actions** タブ →「釣り情報を更新」→「Run workflow」で1回手動実行する。
5. 数分後に `https://<ユーザー名>.github.io/hyogo-fishing/` が開けるようになります。
   スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように使えます。

以降は日本時間の 5・8・11・14・17・20・23時ごろに自動更新されます
（GitHub の混雑で数十分遅れることがあります）。

## 手元で動かす

Python 3.10 以上があれば、追加インストールなしで動きます。

```bash
python3 collect.py                          # docs/data.json を作る（約2分）
python3 -m http.server 8000 -d docs         # http://localhost:8000 で表示
```

## カスタマイズ

- **釣り場を追加・変更**: `config/spots.json` を編集します。
  - `keywords`: 釣果記事の振り分けに使う地名（タイトルの中で最初に出てくる地名で判定）
  - `tide`: 潮汐の観測地点（`KB`神戸 `AK`明石 `K1`姫路 `ST`洲本 `AM`尼崎 `J5`西宮）
  - `sns`: SNS検索に使う語、`anglers`: アングラーズのエリア番号（任意）
- **更新頻度**: `.github/workflows/update.yml` の `cron` を変更します（UTC表記）。

## 釣りメモリーについて

- 写真は長辺1600pxに縮小して、**そのスマホのそのブラウザの中だけ**に保存します（どこにも送信しません）。
- 機種変更・ブラウザのデータ削除で消えるので、ときどき「メモリー → バックアップ → zipで書き出す」で保存してください。
  別の端末でも「zipから復元」で読み込めます。
- iPhone は「ホーム画面に追加」したアイコンから使ってください。Safariのタブのままだと、
  しばらく開かないとデータが削除されることがあります。

## 仕掛け・動画を追加する

`docs/rigs.js` の `RIGS` に1件足すだけです。動画は YouTube の動画ID（`watch?v=` の後ろ）を `videos` に書きます。

## 注意

- 各サイトには、見出し・短い抜粋・元記事へのリンクだけを表示しています。詳細と写真は元サイトで見てください。
  負荷をかけないよう、同じサイトへのリクエストの間は1.5秒あけています。
- 元サイトのつくりが変わると、その情報源だけ取得に失敗します。その場合は前回のデータが表示され、
  トップ画面下の「情報源と取得状況」に ✗ が付きます。
- 潮汐は天文潮位（予測値）です。風や気圧で実際の潮位は変わります。
